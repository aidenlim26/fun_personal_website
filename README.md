# Aiden Lim’s portfolio

A single-page portfolio built with the Next.js App Router and TypeScript. The page and its social preview are generated at build time.

```bash
npm install
npm run dev
npm run lint
npm run build
```

Edit profile copy in `lib/content.ts`. Check new details against Aiden’s LinkedIn profile before adding them. The homepage and section navigation live in `app/page.tsx`, with layout and typography in `app/globals.css`. The social preview uses the same profile data.
